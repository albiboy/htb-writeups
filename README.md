## Methodology

Every writeup follows a consistent structure based on real-world pentest reporting:

1. **Reconnaissance** — passive and active information gathering
2. **Enumeration** — service and vulnerability discovery
3. **Exploitation** — gaining initial access
4. **Post-Exploitation** — privilege escalation and persistence
5. **Remediation** — recommendations for each finding
